# Parkour-Game
A Parkour game built with the open source game engine Godot

## How to play:
  1. Download parkour_game.exe to desired location
  2. Open file and play!
  3. Use the keys W and S to move forward and backward and A and D to rotate your character
  4. Reach the red flag to win!
